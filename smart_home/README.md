# 产品说明
一.项目简介：
桌面智能管家是一款基于小米 AIoT 开发平台 U2P-X3M 和高性能地平线 X3M AI 主控的桌面级智能环境管家。
产品集环境监测、智能联动控制、语音交互、可视化显示于一体，充分利用小米云端 AI 能力（ASR 语音识别、NLP 自然语言理解、
TTS 语音合成），结合本地传感器与执行器，为用户打造一个懂需求、会节能、可对话的桌面智能生态核心。

二.核心亮点
1. 小米云端 AI 赋能：ASR 语音识别 + NLP 语义理解 + TTS 语音合成 + 技能扩展。
2. 全面环境感知：温湿度 + 光照 + 人体红外，实时监测桌面微环境。
3. 智能联动控制：工作 / 休闲 / 睡眠三场景，自动调节风扇与灯光。
4. 四模交互方式：语音 + 物理按键 + 触控屏 + 手机远程。
5. 双屏可视化：E1 数码管快速预览 + E5 触控屏深度交互。
6. 节能设计：人体感应自动待机，断网保留基础控制。

# 快速开始
硬件安装：按照硬件配置表将各子板插入对应槽位（注意堆叠顺序）
确保所有排线连接牢固，电源适配器供电正常
打开电源开关，等待系统启动
# 软件部署
1. 编译项目
bash
cd /path/to/project
make clean
make
2. 启动主程序
bash
sudo ./smart_hub
主程序启动后会：
    自动探测所有 I2C 子板
    初始化各模块
    进入主循环，每 50ms 轮询传感器和按键
    每 5 秒打印一次系统状态
3. 启动 Web 服务（E5 触控屏）
bash
cd web
./run_server.sh 8000
# 或
python3 server.py 8000
4. 访问触控界面
在 E5 屏幕或 PC/手机浏览器中访问：http://<设备IP>:8000

# 常见问题
Q：语音交互需要联网吗？
A：ASR/NLP/TTS 依赖云端 API，需要联网。断网时自动降级为本地关键词匹配 + 本地 TTS。

Q：如何查看设备 IP？
A：在终端执行 ifconfig 或 ip a，查看 eth0 的 IP 地址。

Q：传感器数据不更新怎么办？
A：检查对应子板连接是否牢固；主程序每 2 秒采集一次温湿度，每 50ms 采集光照和人体。

Q：如何恢复出厂设置？
A：重新烧录程序。所有阈值和模式在断电后会复位为默认值。
